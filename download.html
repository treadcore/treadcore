Get treadcore for your system

Pick your system. Each one has a way in that its own users will recognise: a package where there is a package manager to take it, make install where building from source is the custom, and a zip where there is neither.

Packages

From source, with make install

Debian

Debian 12 or newer. The package brings what the window needs: the Wayland and xkbcommon libraries, the Vulkan loader and Mesa's Vulkan drivers, so a machine with no GPU still runs it.

Download for x86-64ARM64 
sudo apt install ./treadcore-*-linux-amd64.deb
treadcore --solo

Treadcore is then in the applications menu under Games. sudo apt remove treadcore takes it out.

Ubuntu

Ubuntu 22.04 or newer. The package brings the Wayland and xkbcommon libraries, the Vulkan loader and Mesa's Vulkan drivers.

Download for x86-64ARM64 
sudo apt install ./treadcore-*-linux-amd64.deb
treadcore --solo

Treadcore is then in the Activities overview and the app grid.

Linux Mint

Linux Mint 21 or newer, Cinnamon, MATE or Xfce. It is the Ubuntu package: double-click the downloaded file and the Package Installer takes it from there, or use the terminal.

Download for x86-64 
sudo apt install ./treadcore-*-linux-amd64.deb

In Cinnamon, Treadcore is in the menu under Games, and can be dragged to the panel from there.

Fedora

Fedora 40 or newer. The package names the Wayland and xkbcommon libraries, the Vulkan loader and mesa-vulkan-drivers; dnf fetches whatever is missing.

Download for x86-64AArch64 
sudo dnf install ./treadcore-*-linux-x86_64.rpm
treadcore --solo

NixOS and Nix

The flake builds the game from source with nixpkgs' own Rust and wraps it with the libraries the window loads at run time. Flakes must be enabled.

nix run github:treadcore/treadcore            # play, without installing
nix profile install github:treadcore/treadcore  # install

On NixOS the Vulkan driver comes from hardware.graphics.enable = true;. With Nix on another distribution, start it through nixGL if the GPU's driver is not found.

The flake is new with this release and has not yet been built by its author on a Nix machine. A report of how it went is welcome.

Windows

Windows 10 or 11, 64-bit. Nothing to install first: the window uses DirectX 12 or Vulkan from the GPU's own driver.

Download the zip

Unzip it anywhere and run treadcore.exe. It opens solo; for a LAN game, from a terminal in that folder: treadcore.exe --lan. Windows will ask once whether to let it through the firewall: allow it on private networks, or other players cannot find you.

The executable is not signed, so SmartScreen may warn the first time: More info, then Run anyway. The Windows build is made by the release workflow and has not yet been played on Windows by its author: a report of how it went is welcome.

macOS

macOS 11 or newer on Apple silicon. The zip holds Treadcore.app and the headless treadcore-server.

Download the zip

Unzip it and drag Treadcore.app to Applications. It is signed ad hoc, not by an Apple developer account, so the first time: right-click it, Open, then Open again. macOS asks whether it may find devices on the local network; allow it for LAN games.

Or from source, which also gives you the traces and the scripts:

git clone https://github.com/treadcore/treadcore.git && cd treadcore
make install        # Treadcore.app into ~/Applications, the commands into ~/.local/bin

Copal Linux

The system treadcore is made on. From source, with your own Rust: make deps names the apk packages and make install puts the game in the Super+Space menu, behind the small wrapper musl needs for the software Vulkan driver.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
APPLY=1 make deps     # apk add ... through doas
make install          # ~/.local/bin, the menu entry and the icon

Treadcore is then in the Super+Space menu under Games. make uninstall takes it out.

Alpine Linux

As on Copal: from source with your own Rust. On a machine with no GPU, make deps includes mesa-vulkan-swrast, and make install wraps the window with the stack fix musl needs for it.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
APPLY=1 make deps
make install

Arch Linux

From source, the Arch way. make deps names the pacman packages, vulkan-swrast among them for a machine with no GPU; add your GPU's Vulkan driver if it is not already there. Rust from rustup or pacman -S rust, as you prefer.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
APPLY=1 make deps     # pacman -S --needed ... through sudo
make install

An AUR package is planned.

Omarchy

Omarchy is Arch with Hyprland, and treadcore is at home there: it runs native on Wayland. Install as on Arch; make deps knows it is Omarchy.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
APPLY=1 make deps
make install

Treadcore is then in the app launcher (Super+Space).

Gentoo

From source, naturally. make deps prints the emerge line; Mesa's Vulkan drivers follow USE=vulkan and VIDEO_CARDS, with lavapipe for a machine with no GPU.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
make deps             # emerge --ask --noreplace ...
make install

An ebuild is planned.

Anywhere, with cargo

Any system with Rust 1.85 or newer: rustup's, or your distribution's. The crate builds the window from source; the system packages it needs are the ones make deps lists for your system.

cargo install treadcore-client     # the window, as `treadcore`
cargo install treadcore-server     # the headless host and bot seat
treadcore --solo

On musl (Copal, Alpine) with the software Vulkan driver, prefer make install, which adds the stack fix the window needs there.
