Sixteen tanks · one island · no server

treadcore

An overhead tank game for the drone battlefield. Your gun fires where your recon drone looks; your interceptors keep the sky over you.

Download How to play Build from source

MIT · 0.1.0-rc.4 · Linux, macOS, Windows · bots fill empty seats

Get it

One line for your system. The package brings what the game needs.

Debian, UbuntuLinux Mint, .deb
sudo apt install ./treadcore-*.deb
installs Wayland, xkbcommon, Vulkan loader, Mesa Vulkan drivers
Fedora.rpm
sudo dnf install ./treadcore-*.rpm
installs Wayland, xkbcommon, vulkan-loader, mesa-vulkan-drivers
Windows.msi installer
treadcore-*-windows-x86_64.msi
installs nothing: DirectX 12 or Vulkan from the GPU driver
macOSApple silicon, .app
Treadcore.app
installs nothing: Metal
NixOS, Nixflake
nix run github:treadcore/treadcore
installs everything, from the flake
Copal, Alpinemake install
make deps && make install
installs apk: wayland, xkbcommon, alsa, eudev, vulkan, mesa-vulkan-swrast
Arch, Omarchymake install
make deps && make install
installs pacman: wayland, libxkbcommon, alsa-lib, vulkan-icd-loader, vulkan-swrast
Gentoomake install
make deps && make install
installs emerge: wayland, libxkbcommon, alsa-lib, vulkan-loader, mesa
Anywherecargo install
cargo install treadcore-client
installs your own Rust 1.85+, and make deps for the system

Play

The mouse drives and fires; the keys give orders. The guide has the rest.

AimHold right: the gun's reach lights. Release to fire.
OrderPick a mode on the left, click a square.
WatchEvery tank, pillbox and depot, by owner.
Play togetherUp to sixteen. The windows elect a host.

Build it

With your own Rust, 1.85 or newer.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
make deps        # what this system needs, by its own names (APPLY=1 installs it)
make install     # into ~/.local, with a menu entry
make run         # or play from the tree, against fifteen bots
