Sixteen tanks · one island · no server

Treadcore

An overhead tank game for the drone battlefield. Your gun fires where your recon drone looks; your interceptors keep the sky over you.

The gun

Fire at what your drone can see.

  • Indirect fire. The gun lobs a shell at a point; it lands where a recon drone is watching, or blind.
  • Interceptors hold a ring round the hull and rip enemy drones out of the sky.
  • Strike and longshot drones carry the fight past the horizon, one way.

The tank was just handed a new battlefield. The game is about the sky over it.

The fleet

Bots that hold a line and never stand about.

  • Fleets of five: a leader on the autopilot, a guard, rangers and wingmen in a wedge.
  • Rotation. Every tank has a defense point at its base and a push point halfway to the objective, and goes between them.
  • Pings and talk. A bot that calls a target says so in team chat; the minimap rings where.

Empty seats fill with bots that play like a side, not a crowd.

The squad

Take the pillboxes. Build the fortress.

  • Pillboxes move. The squad lifts one, carries it home and sets it down at the gate.
  • Walls and roads. A ring of wall outside, a ring road inside, a depot in the middle to refill.
  • Bridges before boats. Three tiles a trip, laid from the material the squad gathers.

Hold the island's depots and pillboxes and the match is yours.

The network

Sixteen players. No server.

  • The windows elect a host. They find each other on a LAN or through an introducer, measure the latency, and pick.
  • Late arrivals take a bot's seat mid-match; a rematch is one key.
  • 4× speed. The host runs the match at 1×, 2× or 4×, and every window follows.

Free, MIT, written in Rust with Bevy. Everything drawn is a rectangle.

Get it

One line for your system. The package brings what the game needs.

Debian, UbuntuLinux Mint, .deb
sudo apt install ./treadcore-*.deb
installs Wayland, xkbcommon, Vulkan loader, Mesa Vulkan drivers
Fedora.rpm
sudo dnf install ./treadcore-*.rpm
installs Wayland, xkbcommon, vulkan-loader, mesa-vulkan-drivers
Windows.msi installer
treadcore-*-windows-x86_64.msi
installs nothing: DirectX 12 or Vulkan from the GPU driver
macOSApple silicon, .app
Treadcore.app
installs nothing: Metal
NixOS, Nixflake
nix run github:treadcore/treadcore
installs everything, from the flake
Copal, Alpinemake install
make deps && make install
installs apk: wayland, xkbcommon, alsa, eudev, vulkan, mesa-vulkan-swrast
Arch, Omarchymake install
make deps && make install
installs pacman: wayland, libxkbcommon, alsa-lib, vulkan-icd-loader, vulkan-swrast
Gentoomake install
make deps && make install
installs emerge: wayland, libxkbcommon, alsa-lib, vulkan-loader, mesa
Anywherecargo install
cargo install treadcore-client
installs your own Rust 1.85+, and make deps for the system

Play

The mouse drives and fires; the keys give orders. The guide has the rest.

AimHold right: the gun's reach lights. Release to fire.
OrderPick a mode on the left, click a square.
WatchEvery tank, pillbox and depot, by owner.
Play togetherUp to sixteen. The windows elect a host.

Build it

With your own Rust, 1.85 or newer.

git clone https://github.com/treadcore/treadcore.git && cd treadcore
make deps        # what this system needs, by its own names (APPLY=1 installs it)
make install     # into ~/.local, with a menu entry
make run         # or play from the tree, against fifteen bots
SPEED=4 make quad # three windows, a team each, on the autopilot, at 4x
